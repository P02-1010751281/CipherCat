| 类目 | 块数 | 覆盖评价 |
|------|------|---------|
| 控制流 (ctrl) | 1 | 基础 |
| 数据与转换 (data) | 9 | 良好 |
| 数组 (array) | 1 | 基础 |
| 逻辑运算 (logic) | 3 | 良好 |
| 位运算 (bitwise) | 8 | **优秀** |
| S-box (sbox) | 4 | **优秀**（可自定义 CSV） |

## 二、覆盖评价

### ✅ 已完整覆盖

- 位运算全系列（AND/OR/XOR/NOT/移位/循环/取反/字节替换）
- 可自定义 S-box（CSV 导入导出 + 变量系统）
- SHA-256 填充 + 压缩函数
- Keccak/SHA-3 海绵结构（状态/填充/Keccak-f/吸收/挤压）
- **SM3 填充 + 压缩函数** ✅
- SHAKE XOF/PRF
- 模运算 (Z_q) / 模逆
- NTT/INTT（支持 Kyber q=3329）
- ECC 曲线点运算（加载/加倍/加法/标量乘）
- ML-KEM 底层全套（BytesToBits/ByteEncode/Compress/SampleNTT/CBD 等）
- 类型约束系统（Bytes/IntList/SBox + TYPE_MAP）

## 三、国密标准专项分析

### SM3 (GM/T 0004-2012) — ✅ 完整覆盖

| 块名 | 功能 | 评价 |
|------|------|------|
| `hash_sm3_pad` | 消息填充（1\|\|0*\|\|64-bit 长度） | 标准实现 |
| `hash_sm3_pad_text` | UTF-8 文本填充 | — |
| `hash_sm3_pad_hex` | 十六进制填充 | — |
| `hash_sm3_compress` | 64 轮压缩函数（FF0/FF1, GG0/GG1, P0, P1, 消息扩展 W/W', 常数 Tj） | 完整实现 |

**缺失**：一键式完整哈希块、HMAC-SM3 专用块。

### SM4 (GM/T 0002-2012) — ❌ 无专用块，已提升至 P0

SM4 是中国商用分组密码标准（128-bit 分组，128-bit 密钥，32 轮）：

| 组件 | CipherCat 现有支撑 | 需新增 |
|------|-------------------|--------|
| S-box（16×16 固定置换） | ✅ 通用 `sbox` 块 + `test/SM4轮密钥生成.json` 含 SM4 S-box | 可复用 |
| 线性变换 L(B) | ✅ `bit_rotate_left` + `bit_operation` 可组合 | 建议封装专用块 |
| 轮函数 F | ✅ 底层原语齐全 | 需专用封装块 |
| 密钥扩展 | ✅ CK/FK 参数可用 `data_value` | 需专用封装块 |
| 加密/解密 | — | 需新增 |
| 分组模式 | — | 需新增（ECB/CBC/CTR/GCM） |

**历史记录**：`migration.ts` 中 `crypto_sm4_sbox_sub` → `sbox_sub` 表明旧版曾有过 SM4 S-box 替换专用块，已被合并到通用 S-box 框架中。

### SM2 (GM/T 0003-2012) — ⚠️ 可组合实现

| 协议 | 需新增块 | 说明 |
|------|---------|------|
| 曲线参数 | SM2 专用参数预设块 | 已有通用 `ecc_load_curve_params`，需预设 p/a/b/G/n |
| 数字签名 | 签名块 + 验签块 | 需要 SM3 哈希 + 随机数 k + 模逆 |
| 公钥加密 | 加密块 + 解密块 | 需要 KDF(SM3) + SM3 哈希 |
| 密钥交换 | 密钥交换块 | 需要 KDF(SM3) + 双方交互 |

### ZUC (GM/T 0001-2016) — ❌ 完全缺失

祖冲之序列密码，包含 LFSR（16级31-bit）、比特重组(BR)、非线性函数 F（含 S-box）。需要全新实现，难度高。

### SM9 (GM/T 0044-2016) — ❌ 完全缺失

基于双线性对的标识密码，包含数字签名、密钥交换、公钥加密。需要双线性对运算（Weil/Tate pairing），实现难度极高。

### 国产后量子密码标准化进展

- 中国密码学会后量子密码标准化工作组（2022 年成立）
- **截至 2026 年中**：尚未公布正式标准
- 候选方向：基于格（lattice-based）和基于编码（code-based）
- CipherCat 已有 ML-KEM (FIPS 203) 全套原语，与格的密码方向一致，届时可大幅复用

## 五、核心结论

CipherCat 在**后量子密码（ML-KEM）**和 **Keccak/SHA-3 海绵结构**方面是国内最强的可视化编程平台。SM3 覆盖完整，数论基础和 ECC 曲线运算扎实。

**对称密码是最大缺口**——双线缺失：
- 国际线：无 AES（密码学教学第一重点）
- 国密线：无 SM4（中国商用密码核心标准）

补齐 AES + SM4 + 分组模式 + 填充 + HMAC + RSA 即可覆盖密码学课程 90% 核心教学需求，同时满足国际和国密双线教学要求。
