# GB/T 17964 — 分组密码操作模式

来源: GB/T 17964-2008 — 信息安全技术 分组密码算法的工作模式
      下载: https://openstd.samr.gov.cn/ (需登录)

## 模式

| 模式 | 名称 | 对标 | CipherCat |
|------|------|------|----------|
| ECB | 电码本 | NIST SP 800-38A | `mode_ecb` |
| CBC | 密码分组链接 | 同上 | `mode_cbc` |
| CFB | 密码反馈 | 同上 | 未实现 |
| OFB | 输出反馈 | 同上 | 未实现 |
| CTR | 计数器 | 同上 | `mode_ctr` |

> 国产分组密码模式与国际标准一致，CipherCat 的 mode_* 块可同时用于 AES 和 SM4。

## 未覆盖

| 模式 | 说明 |
|------|------|
| BC | 块链接 (中国特有) |
| OFB-8 | 8-bit OFB 变体 |
