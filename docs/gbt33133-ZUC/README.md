# GB/T 33133 — ZUC 祖冲之序列密码算法

来源: GB/T 33133-2016 — 信息安全技术 祖冲之序列密码算法
      下载: https://openstd.samr.gov.cn/ (需登录)

## 参数

| 参数 | 值 |
|------|-----|
| 密钥长度 | 128 bit (ZUC-128) |
| IV 长度 | 128 bit |
| 输出 | 32-bit 密钥流字 |

## 结构

| 组件 | 说明 |
|------|------|
| LFSR | 16 级线性反馈移位寄存器 (31-bit cells) |
| BR | 比特重组 (从 LFSR 提取 4×32-bit) |
| F | 非线性函数 (含 S-box) |
