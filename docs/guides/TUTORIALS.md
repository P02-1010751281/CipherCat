# 用户教程：用积木块拼出算法

本教程的主线是**用积木块从零拼出算法**：拖块 → 连线 → 生成代码。

请把 Procedure 模板和 Demo 理解为**便利起点**（省去重复拖块），而不是能力本身。平台的能力边界是“能不能用块拼出来”；模板与 Demo 存在与否，不影响这一判断。因此下面的步骤**不使用导入 Demo**，需要导入的部分集中放在[附录 A](#附录-a想走捷径时导入-demo)。

## 1. 打开编辑器，认清四块区域

**做什么**：在项目列表点击“新建项目”。

**看到什么**：编辑器打开后分成四块——左侧工具箱（按类别分组的块）、中间工作区（拼块的地方）、右上角语言选择（JavaScript / Python）、右侧代码面板。

**若不对**：页面空白就刷新，并确认前端服务可访问；只有工具箱没有工作区时看浏览器控制台是否有 Blockly 初始化报错。

![项目列表与新建项目入口](/docs-assets/tutorials/01-project-list.png)

![空白编辑器：工具箱、工作区、语言选择与代码面板](/docs-assets/tutorials/02-editor-empty.png)

_图 1：项目入口与空白编辑器。_

## 2. 从工具箱拖出第一个块

**做什么**：在左侧工具箱展开一个类别（例如「哈希 / 填充」），把 `SHA-256 填充` 块拖到工作区。

**看到什么**：工作区出现一个块，块上带输入插槽（值输入）或上下连接口（语句块）。此时代码面板还没有内容——没有连接到输出/返回的块不会进入生成结果。

**若不对**：块拖不出来时先确认工具箱类别已展开；块显示为灰色说明连接类型不匹配，需要换成匹配的插槽。

> 提示：每个块只做一件事（例如“填充”“压缩”“异或”），算法靠把它们连起来完成——这正是本平台的设计前提。

![展开“哈希与填充单元”类别后的工具箱](/docs-assets/tutorials/10-toolbox-category.png)

![从工具箱拖到工作区的第一个块](/docs-assets/tutorials/11-first-block.png)

_图 2：展开工具箱类别（左），把 `SHA-256 填充` 拖到工作区（右）。_

## 3. 把块连接成算法阶段链

**做什么**：拖出第二个块（例如 `SHA-256 压缩`），把它左边的输入插槽连到第一个块的输出插槽；需要输入数据时，拖出数据块（如十六进制/字节常量）接到最上游。

**看到什么**：块之间出现连线，形成“数据 → 阶段 1 → 阶段 2”的链；此时链尾仍未接到输出，代码面板仍为空。

**若不对**：连线连不上通常是类型不匹配（块插槽有颜色/形状提示），按[用户指南：数据类型与积木连接](./USER-GUIDE.md)选择匹配类型。

![把填充块的输出接到压缩块的输入](/docs-assets/tutorials/12-block-chain.png)

_图 3：把第一个块的输出插头拖到第二个块的输入插槽（`V=`）上，两块即连成一段链。_

## 4. 生成 JavaScript 或 Python 代码

**做什么**：在右上角选择目标语言，然后点击“生成”。

**看到什么**：右侧代码面板出现完整代码，函数顺序与工作区里的块链一致；切换语言后再生成，会得到另一种语言的等价代码。

**若不对**：代码为空说明链没有接到顶层输出/返回；类型不匹配时先看用户指南的数据类型章节。

![生成代码后的工作区与代码面板](/docs-assets/tutorials/13-generate-code.png)

_图 4：选择 Python 后点击“生成”，右侧代码面板出现对应实现；切换语言可得到 JavaScript 版本。_

## 5. （可选）把块链封装成可复用函数

**做什么**：拖入函数定义块（`procedures_defreturn`），给一个参数（例如 `x: int` 或 `msg: message`），把上一步的块链接到它的返回接口。

**看到什么**：函数块上出现参数行与返回接口；生成代码里出现对应的函数实现。

**若不对**：参数类型必须与链上第一个块的输入类型一致；不确定就用与数据块相同的类型。

![带参数与返回接口的函数定义块](/docs-assets/tutorials/08-function-demo.png)

_图 5：把块链封装成函数，并在生成代码中复用。_

## 6. 分清三件事：块链、测试证据、后端测评

拼出块链只说明**能生成代码**；它不等于算法正确，更不等于通过标准或认证。判定要按下面的层级分别看：

| 层级 | 看什么 | 在哪里 |
|---|---|---|
| 块与连线 | 结构对不对、类型是否匹配 | 编辑器工作区 |
| 可执行性 | 生成的 JS/Python 能否运行 | 代码面板 / 本地运行 |
| 规范符合性 | 是否覆盖标准的接口与参数集、能否对齐官方向量 | `docs/standards/` 的覆盖矩阵与逐块证据 |
| 后端测评 | 样本的统计检测结论 | Metacrypto 平台的任务与报告 |

## 7. 查看平台后端随机性测评

**做什么**：在 Metacrypto 平台进入“任务 → 随机性测试”，选择或提交算法并填写测评参数，然后在任务列表打开详情。

**看到什么**：表单读取项目预检结果（算法类型只读），提交后得到任务编号；任务详情显示后端返回的摘要、检测明细和参数字段。

**注意**：前端不生成平台测评样本、也不在浏览器里执行服务端传来的代码；统计检测通过不等于密码算法认证。报告里是否存在规则/检测器版本字段，以实际返回为准，不要写成“已追溯”。字段与判定边界见 [GM/T 0005 测评边界](../standards/gmt0005-randomness/03-Backend-Evaluation.md)。

## 附录 A：想走捷径时导入 Demo

Demo 与 Procedure 模板省去重复拖块，适合快速看清一条完整链路；但它们**不是必需**，也不改变“能力本体是能用块拼出来”这一点。

- **导入工作区**：`更多 → 导入工作区`，选择 `demos/` 下的 JSON（例如 `demos/AES-Atomic-Round.json`）。
- **拖出模板**：把 Procedure 模板块拖到工作区，它会预填一段结构（例如 ML-KEM 封装的 28 条语句链）；模板默认留空的参数需要自己补全。
- **模板的边界**：模板预填 ≠ 完整算法，也不等于通过测试；每项的覆盖范围见[符合性对象清单](../standards/CONFORMANCE-INVENTORY.md)。

![“更多”菜单中的导入入口](/docs-assets/tutorials/03-import-menu.png)

_图 6：导入入口。仅在走捷径时使用；主线教程不需要它。_
