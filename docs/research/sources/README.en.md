# Supplementary NIST Publications

[简体中文](./README.md)

This directory stores three NIST source PDFs cited by the randomness research. The index records official publication pages and SHA-256 values so local copies can be checked against the reviewed versions. Statistical-test results are diagnostic evidence only; they do not certify a random-number generator.
