## Status semantics

- `source line anchor`: the entry links to a local source extraction line range.
- `source PDF page anchor`: the entry identifies the exact physical PDF page(s), including a PDF page jump link.
- `RFC .txt evidence`: the complete RFC Editor text is stored locally; the structured page is an index/summary and must not impersonate a full quotation.
- `research bibliography link`: a local research index provides bibliographic/contextual evidence, not a normative-standard extraction.
- `official source record only`: an official catalog record is linked, but no local normative text or clause-level citation is available.
- `scanned PDF extraction gap`: a local scanned PDF is linked, but reliable searchable text or a page-level citation is not yet available.
- `source section anchor`: the entry links to the source layer but still needs a finer line range or PDF page when the section can be uniquely identified.
- `missing source link`: allowed only for explicitly documented external, historical, or source-gap directories.
