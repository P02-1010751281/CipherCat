# 标准条目结构

标准目录中的 `00-Standard-Source.md` 是标准原文的结构化拆分输入和回溯入口：拆分出的函数、
原语、算法阶段、公式和表格必须先从这里定位，再回到 PDF 视觉版式核验。Blockly 构建和用户
查阅使用同目录的结构化条目页；一个条目对应一个可独立核对的函数、原语、算法阶段或公式族，
而不是把整份 PDF 再复制一遍。`00-*` 可以保留 PDF 转文本的原貌，但不能用失真的文本层替代
原文，也不能因为另有摘要页就省略源文档中的定义、伪代码、公式或表格。

## 固定字段

每个已拆分条目按下列顺序组织。若标准没有该字段，必须写明“标准未定义”或“项目未实现”，
不能留空，也不能用项目行为反推标准定义。

```markdown
## 条目元数据

| 字段 | 内容 |
|---|---|
| 类型 | 函数 / 原语 / 公式 / 算法阶段 / 协议 |
| 标准定位 | 标准名称、版本、章节或算法编号 |
| 原文证据 | `00-Standard-Source.md` 的对应章节、原件链接和必要时的 PDF 页面 |
| 原文位置 | PDF 物理页、标准页码（如有）以及提取稿行号链接 |
| 项目状态 | 已实现 / 部分实现 / 仅参考 / 缺项 |

## 标准定义

只写由标准直接支持的定义和前置条件。

## 原文定位与引用

这一节必须让读者从条目页回到原始证据。`原文位置`至少写标准章节或算法编号，能够核对时再写
PDF 物理页和 `00-Standard-Source.md#L...` 行号链接；PDF 版本存在封面/罗马页码差异时，明确写
“PDF 物理页”和“标准页码”，不要把两者混称。公式、伪代码、算法步骤和表格不能用“短片段”、省略号
或项目摘要代替：必须完整保留该规范单元的原文内容、顺序、符号和边界，跨页内容要连续摘录到结束。
只允许从原文摘录中移除页眉、页脚、页码、分页标记等版式家具，并在提取失真时标明需回看 PDF。
普通说明文字可以在“原文定位与引用”中使用短引文，但不能冒充公式或伪代码的完整摘录；完整上下文
通过链接回看，不在条目页复制与本条目无关的整页标准。

## 公式或伪代码

完整保留本条目所属规范单元的公式或伪代码；不得裁成短摘录或用项目摘要代替。符号、字宽、模数、字节序必须注明。若该页是导航/组合/边界页、没有独立归属的规范单元，明确写“本条目无独立公式/伪代码规范单元”并链接所属完整条目；若标准确实没有该字段，写“标准未定义”，并链接所属完整原文段落。

RFC 目录是唯一的标准原文证据层例外：RFC Editor `.txt` 原文在仓库中完整保存时，结构化页可以作为章节索引、测试向量和项目映射页，不重复复制整段 RFC。此时必须在“原文摘录”和“公式或伪代码”中明确写出“RFC `.txt` 证据层条目”，给出 RFC 章节与本地文本行号，并链接完整 `.txt`；不得把摘要标成完整算法摘录。

研究/参考目录若 manifest 标为 `kind=reference`，可以使用 `00-Research-Source.md` 作为书目与背景来源索引，但它不等同于标准原文提取层。此类结构化页面必须明确标注“来源要点（转述，非逐字引用）”，给出可访问的原始文献、标准记录或 DOI，并说明全文访问/转录边界；不能把转述计为标准原文行号锚点，也不能替代缺失的标准原文。所有 `current` 标准目录仍必须保留完整规范单元原文并满足上述字段。

## 输入与输出

说明类型、长度、取值域、错误条件和输出编码。

## 项目映射

列出 Blockly 块、源码入口、模板或明确写“没有独立块”。

## 核验与缺项

列出标准向量/性质向量/交叉实现、已验证范围和剩余缺项。
```

## 拆分粒度

- 标准中有独立算法编号的函数，独立成页。
- 可单独作为 Blockly 块或教学中间值的原语，独立成页。
- 只服务于同一函数的内部公式，放在该函数页的“公式或伪代码”字段，不为每一行公式制造文件。
- 密切耦合且没有独立块的步骤可以成组，但必须在“项目映射”中标注“由上层块内部实现”。
- 概览页只做导航；`00-Standard-Source.md` 是拆分输入而不是拆分结果；缺项页不冒充实现页。

## 机器检查约束

新增结构化条目至少应满足：有标准原件链接、有原文定位、有完整的公式/伪代码/算法/表格规范单元
（标准未定义时明确写出）、有输入输出边界、有项目映射、有核验或缺项结论。文档检查脚本只检查这些
可机械验证的字段，完整性和标准语义仍需人工对照原文、PDF 版式和向量。

## i18n

中文条目使用 `.md`，英文译本使用同路径的 `.en.md`。公式、伪代码、符号、标识符和原文引文属于
证据层，两种语言必须保持不变；说明文字、字段标签和导航可以翻译。英文译本不存在时，Docs 页面
明确显示源语言条目作为回退，不把回退内容冒充英文翻译。
