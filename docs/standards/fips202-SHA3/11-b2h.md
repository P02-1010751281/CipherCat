### 规范

```
Input:  bit string S of length n
Output: hex string H of 2·ceil(n/8) digits

1: n = len(S)
2: T = S ‖ 0^{−n mod 8}, m = ceil(n/8)
3: For each byte: bᵢⱼ = T[8i+j]
4: For i = 0 to m−1:
   a. hᵢ = Σ bᵢⱼ·2^j
   b. H₂ᵢ H₂ᵢ₊₁ = hex digits of hᵢ
5: Return H = H₀…H_{2m−1}
```

### 备注

h2b 的逆运算。不足整字节时补零 (0-pad to byte boundary)。
## 原文摘录
> 以下为 source 中 Algorithm 11 的完整原文算法块；仅移除了 PDF 分页标记和页眉页码。

```text
Algorithm 11: b2h(S).

Input:
bit string S consisting of n bits for a positive integer n.

Output:
hexadecimal string H consisting of 2*ceil(n / 8) digits.

Steps:

1.       Let n = len(S).
2.       Let T = S || 0-n mod 8 and m = ceil(n/8).
3.       For each pair of integers (i, j) such that 0 ≤ i < m and 0 ≤ j < 8, let bij = T [8i + j].
4.       For each integer i such that 0 ≤ i < m:
         a. Let hi = bi7⋅ 27 + bi6⋅ 26 + bi5⋅ 25 + bi4⋅ 24 + bi3⋅ 23 + bi2⋅ 22 + bi1⋅ 21 + bi0⋅ 20.
         b. Let H2i and H2i +1 be the hexadecimal digits such that hi = 16 ⋅ H2i + H2i+1.
5.       Return H = H0 H1 H2 H3 … H2m-2 H2m-1.
```
