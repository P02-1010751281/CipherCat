# GB/T 15852 — 消息鉴别码 (MAC)

本目录按分部分维护，不把一个实现块的通过结果写成整套标准覆盖：

- [GB/T 15852.1-2020 官方记录](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=2C2CF7FD11D1AA8C666C0E49A2186CBE)：采用分组密码的机制，现行记录；发布日期 2020-12-14，实施日期 2021-07-01。
- [GB/T 15852.2-2024 官方记录](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=2CE2B006D80BF9D3EE2BAC4CB80C03FB)：采用专用杂凑函数的机制，现行记录；发布日期 2024-09-29，实施日期 2025-04-01。
- [GB/T 15852.3-2019 官方记录](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=FFA0FFF9CF75B3F88FFA437D75334745)：采用通用杂凑函数的机制；官方记录标为现行，发布日期 2019-08-30，实施日期 2020-03-01。

## 内容

GB/T 15852 是消息鉴别码分部分标准。三份国家标准全文公开系统记录均说明，因采标版权保护而不提供标准文本阅读。项目当前只有实现映射，没有随仓库保存上述分部分的标准 PDF；原件需通过授权/许可渠道取得。

## 对应块

✅ `cmac_mac`（CIPHER 下拉 SM4）可映射到基于分组密码的 MAC 路径，但不等于已核验 GB/T 15852.1 的全部条款。
`hash_hmac`（SM3/SHA-256）可映射到基于杂凑的 MAC 路径，但不等于已核验 GB/T 15852.2/3 的全部机制。

## 状态
⚠️ 部分实现映射（`cmac_mac` SM4 分支 + `hash_hmac`）。未完成：分部分条款矩阵、标准向量、截断/验证失败语义、GB/T 15852.3 的机制核验和独立互操作测试。

> 本目录当前没有随仓库保存的标准 PDF；条款、版本和状态应以国家标准全文公开系统记录为准。公开记录可确认状态和日期，但不能替代受版权保护的标准正文。
