## 公式或伪代码

> 以下是面向用户的结构化公式/伪代码摘要，不是标准原文的完整逐字摘录；完整规范单元请以本页“原文摘录”、source 提取稿和 PDF 为准。

### 1. 参数与消息填充

SM3 输出 256 bit，压缩分组为 512 bit，使用 64 轮、32-bit 字运算。

对消息 `M` 进行 `Merkle–Damgård` 式填充：

```text
M' = M || 1 || 0^k || [len(M)]_64
使 len(M') ≡ 0 (mod 512)
```

长度字段是原始消息长度（bit）的 64-bit 大端表示。每个 512-bit 分组拆为
`W[0..15]` 个 32-bit 字。

### 2. 消息扩展

对每个分组计算 `W[0..67]` 与 `W'[0..63]`：

```text
W[j] = P1(W[j-16] xor W[j-9] xor (W[j-3] <<< 15))
       xor (W[j-13] <<< 7) xor W[j-6]                16 ≤ j ≤ 67
W'[j] = W[j] xor W[j+4]                          0 ≤ j ≤ 63
P1(X) = X xor (X <<< 15) xor (X <<< 23)
```

`<<<` 表示 32-bit 循环左移。

### 3. 压缩函数

初始向量为：

```text
7380166f 4914b2b9 172442d7 da8a0600 a96f30bc 163138aa e38dee4d b0fb0e4e
```

令工作变量 `(A,B,C,D,E,F,G,H)` 等于当前链值。第 `j` 轮使用：

```text
T[j]  = 0x79CC4519  (0 ≤ j ≤ 15)
        0x7A879D8A  (16 ≤ j ≤ 63)
SS1   = ((A <<< 12) + E + (T[j] <<< (j mod 32))) <<< 7
SS2   = SS1 xor (A <<< 12)
TT1   = (FF_j(A,B,C) + D + SS2 + W'[j]) mod 2^32
TT2   = (GG_j(E,F,G) + H + SS1 + W[j])  mod 2^32
```

其中：

```text
FF_j(X,Y,Z) = X xor Y xor Z                         (0 ≤ j ≤ 15)
              (X & Y) | (X & Z) | (Y & Z)            (16 ≤ j ≤ 63)
GG_j(X,Y,Z) = X xor Y xor Z                         (0 ≤ j ≤ 15)
              (X & Y) | (~X & Z)                    (16 ≤ j ≤ 63)
```

工作变量每轮更新为：

```text
A = TT1; B = A_old; C = B_old <<< 9; D = C_old
E = P0(TT2); F = E_old; G = F_old <<< 19; H = G_old
P0(X) = X xor (X <<< 9) xor (X <<< 17)
```

以上赋值中的右侧变量均指本轮更新前的旧值。压缩结束后按字逐个异或回链值：

```text
V_(i+1) = V_i xor (A,B,C,D,E,F,G,H)
```
