### 完整哈希

完整路径是：

```text
消息 → SM3 填充 → 分组扩展 → 64 轮压缩 → 256-bit 摘要
```

项目的 `sm3_hash` 高层路径由生成器提供；低层 `hash_sm3_pad` 与 `hash_sm3_compress` 可用于教学拆解。

## HMAC

SM3 也可作为 HMAC 的底层哈希。`hash_hmac` 的 HASH 下拉选择 SM3 时，外层结构仍遵循 HMAC：密钥规范化、`ipad/opad` 两次哈希；这不是 SM3 标准本身新增的压缩函数。
