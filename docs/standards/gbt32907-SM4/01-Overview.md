## 标准定义

SM4 是 128-bit 分组、128-bit 密钥的分组密码。加密和密钥扩展各执行 32 轮；解密使用与加密
相反顺序的轮密钥，数据轮结构相同。

## 公式或伪代码

```text
Input:  MK ∈ {0,1}^128, P ∈ {0,1}^128
ExpandKey(MK) → rk[0..31]
X[0..3] = words_be(P)
for i = 0..31:
    X[i+4] = F(X[i], X[i+1], X[i+2], X[i+3], rk[i])
Y = (X[35], X[34], X[33], X[32])
Output: Y
```

## 输入与输出

| 项目 | 约束 |
|---|---|
| 明文/密文 | 恰好 16 字节 |
| 主密钥 | 恰好 16 字节 |
| 轮密钥 | 32 个 32-bit 字 |
| 解密 | 使用 `rk[31] ... rk[0]` |
