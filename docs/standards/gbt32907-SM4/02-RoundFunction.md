### 6 轮函数 F

设输入为 (X0, X1, X2, X3) ∈ (ℤ₂³²)⁴，轮密钥为 rk ∈ ℤ₂³²，则轮函数 F 见式 (1)：

```
F(X0, X1, X2, X3, rk) = X0 ⊕ T(X1 ⊕ X2 ⊕ X3 ⊕ rk)      (1)
```

## 6.2 合成置换 T

T: ℤ₂³² → ℤ₂³² 是一个可逆变换，由非线性变换 τ 和线性变换 L 复合而成，即 T(·) = L(τ(·))。

### a) 非线性变换 τ

τ 由 4 个并行的 S 盒构成。设输入为 A = (a0, a1, a2, a3) ∈ (ℤ₂⁸)⁴，输出为
B = (b0, b1, b2, b3) ∈ (ℤ₂⁸)⁴，则见式 (2)：

```
(b0, b1, b2, b3) = τ(A) = (Sbox(a0), Sbox(a1), Sbox(a2), Sbox(a3))    (2)
```

### b) 线性变换 L

非线性变换 τ 的输出是线性变换 L 的输入。设输入为 B ∈ ℤ₂³²，输出为 C ∈ ℤ₂³²，则见式 (3)：

```
C = L(B) = B ⊕ (B <<< 2) ⊕ (B <<< 10) ⊕ (B <<< 18) ⊕ (B <<< 24)    (3)
```
