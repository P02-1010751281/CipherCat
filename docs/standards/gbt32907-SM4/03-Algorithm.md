## 标准定义

SM4 加密先将明文拆成四个 32-bit 字，进行 32 次轮迭代，再做反序变换。密钥扩展使用不同的
线性变换 `L'`；解密只反转轮密钥顺序。

## 公式或伪代码

```text
X[i+4] = X[i] xor T(X[i+1] xor X[i+2] xor X[i+3] xor rk[i])
Y = (X[35], X[34], X[33], X[32])

K[0..3] = MK[0..3] xor FK[0..3]
rk[i] = K[i+4]
       = K[i] xor T'(K[i+1] xor K[i+2] xor K[i+3] xor CK[i])

T'(B) = B xor (B <<< 13) xor (B <<< 23)
```

`T` 为 [02-RoundFunction.md](./02-RoundFunction.md) 中的 `L(τ(B))`；密钥扩展中的 `T'`
将 `L` 替换为上式的 `L'`。所有运算在 32-bit 字宽内进行。

## 输入与输出

| 函数 | 输入 | 输出 |
|---|---|---|
| 加密 | 16-byte `P`、16-byte `MK` | 16-byte `Y` |
| 解密 | 16-byte `C`、16-byte `MK` | 16-byte `P` |
| 密钥扩展 | `MK`、`FK`、`CK` | `rk[0..31]`，每项 32 bit |
| 非法输入 | 长度不满足标准分组/密钥长度 | 应由调用方拒绝 |

## 核验与缺项

标准附录 A 示例 1：

```text
MK = 0123456789ABCDEFFEDCBA9876543210
P  = 0123456789ABCDEFFEDCBA9876543210
C  = 681EDF34D206965E86B3E94F536E4246
```

示例 2 的 1,000,000 次迭代密文为 `595298C7C6FD271F0402F804C33D3F66`。向量通过只说明
选定输入的一致性；模式、密钥管理和侧信道不在本条目范围内。
