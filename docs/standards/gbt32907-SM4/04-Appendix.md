## 标准定义

附录 A 给出固定主密钥、明文、轮密钥和轮状态，供实现逐轮比对。附录向量不能改变 §7 的
算法定义，也不能证明所有输入均正确。

## 公式或伪代码

```text
assert SM4_Encrypt(K, P) == C
assert SM4_Decrypt(K, C) == P
assert repeat_encrypt(K, P, 1_000_000) == C_1M
```

## 核验与缺项

应至少检查最终密文、首轮输出 `27FAD345` 和轮密钥顺序。通过附录向量不代表已经覆盖所有模式、
异常输入、性能或认证要求。
