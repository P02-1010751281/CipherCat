## 适用范围与项目边界

本标准规定二元序列的统计随机性检测方法。它检测的是给定输出序列，不是熵源的最小熵评估、健康状态认证或密码模块认证；统计检测通过不能单独证明熵源质量。

GB/T 32915 与密码行业标准 GM/T 0005《随机性检测规范》是不同标准，不应因检测对象相近而视为等同。`metacrypt_server` 当前已有参考 GM/T 0005 的后端测评流程，但尚未完成 GB/T 32915 的逐条适用性和符合性核查。
