    5.1 Fp 上椭圆曲线系统参数
    Fp 上椭圆曲线系统参数包括域的规模 q=p、曲线元素 a 和 b、基点 G=(xG,yG)∈E(Fp)、
    基点 G 的阶 n，以及可选的 SEED 和余因子 h。

    5.2 Fp 上椭圆曲线系统参数的验证
    输入：Fp 上椭圆曲线系统参数的集合。
    输出：若椭圆曲线系统参数有效，则输出“有效”；否则输出“无效”。

## 标准定义

SM2 使用素域上的短 Weierstrass 曲线。点必须满足域范围和曲线方程；公钥还需满足标准规定的
阶条件。无穷远点是群单位元，不能按普通坐标编码。

## 公式或伪代码

```text
y^2 = x^3 + a*x + b (mod p)

PointAdd(P,Q):
    λ = (yQ-yP)/(xQ-xP) mod p          if P != Q
    λ = (3*xP^2+a)/(2*yP) mod p        if P = Q
    xR = λ^2 - xP - xQ mod p
    yR = λ*(xP-xR) - yP mod p
    return R=(xR,yR)

ScalarMul(k,P): double-and-add over k
```

应单独处理 `P=O`、`Q=O`、`P=-Q` 及倍点分母为零的情况；域除法是模 `p` 求逆，不是浮点除法。

## 输入与输出

| 原语 | 输入 | 输出 |
|---|---|---|
| 曲线参数 | `p,a,b,G,n` | 曲线对象 |
| 点加载 | `x,y` | 合法点或错误 |
| 点加/倍点 | 曲线点 | 点或无穷远点 |
| 标量乘 | `k,P` | `[k]P` |

## 核验与缺项

核验 SM2 标准基点在曲线上、`[n]G=O`、点加/标量乘往返及非法点拒绝。仿射大整数实现用于教学，
不保证生产侧信道安全；完整协议互操作仍需分别验证。
