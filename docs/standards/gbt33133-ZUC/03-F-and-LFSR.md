## 公式或伪代码

### LFSR 状态

LFSR 包含 16 个 31-bit 寄存器单元 `s0, s1, ..., s15`。运行模式为初始化模式和工作模式。

### 初始化模式

```text
LFSRWithInitializationMode(u):
    v = (2^15*s15 + 2^17*s13 + 2^21*s10 + 2^20*s4
         + (1 + 2^8)*s0) mod (2^31 - 1)
    s16 = (v + u) mod (2^31 - 1)
    if s16 == 0:
        s16 = 2^31 - 1
    (s1, s2, ..., s15, s16) -> (s0, s1, ..., s14, s15)
```

### 工作模式

```text
LFSRWithWorkMode():
    s16 = (2^15*s15 + 2^17*s13 + 2^21*s10 + 2^20*s4
           + (1 + 2^8)*s0) mod (2^31 - 1)
    if s16 == 0:
        s16 = 2^31 - 1
    (s1, s2, ..., s15, s16) -> (s0, s1, ..., s14, s15)
```

模 `2^31 - 1` 的乘法和加法实现见标准附录 B。

## 密钥装入

```text
k  = k0 || k1 || ... || k15
iv = iv0 || iv1 || ... || iv15
s_i = k_i || d_i || iv_i,  0 <= i <= 15
```

其中 `k_i` 和 `iv_i` 是 8-bit 字节，`d_i` 是标准定义的 16-bit 常量：

```text
d0=100010011010111  d1=010011010111100  d2=110001001101011  d3=001001101011110
d4=101011110001001  d5=011010111100010  d6=111000100110101  d7=000100110101111
d8=100110101111000  d9=010111100010011  d10=110101111000100 d11=001101011110001
d12=101111000100110 d13=011110001001101 d14=111100010011010 d15=100011110101100
```

## F 函数

`F` 包含 32-bit 记忆单元 `R1` 和 `R2`，输入 `X0, X1, X2`，输出 32-bit 字 `W`。

```text
F(X0, X1, X2):
    W  = ((X0 xor R1) + R2) mod 2^32
    W1 = (R1 + X1) mod 2^32
    W2 = R2 xor X2
    R1 = S(L1(W1_L || W2_H))
    R2 = S(L2(W2_L || W1_H))
    return W
```

```text
L1(X) = X xor rotl32(X, 2) xor rotl32(X, 10)
          xor rotl32(X, 18) xor rotl32(X, 24)
L2(X) = X xor rotl32(X, 8) xor rotl32(X, 14)
          xor rotl32(X, 22) xor rotl32(X, 30)
```

`S`、`L1`、`L2` 的完整定义见 [02-SBox-Linear.md](./02-SBox-Linear.md)。

## ZUC 初始化

```text
ZUC_Initialization(k, iv):
    load s0..s15 using s_i = k_i || d_i || iv_i
    R1 = 0
    R2 = 0
    repeat 32 times:
        (X0, X1, X2, X3) = BitReconstruction()
        W = F(X0, X1, X2)
        LFSRWithInitializationMode(W >> 1)
```

初始化阶段输出的 `W` 不作为密钥流输出。初始化完成后，执行一次不输出的工作轮，再进入 [密钥流工作步骤](./04-Keystream.md)。
