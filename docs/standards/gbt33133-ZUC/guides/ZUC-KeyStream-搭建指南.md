# ZUC 密钥流生成 — 搭建指南

> GB/T 33133.1-2016 算法流程（密钥装入 → 32 轮初始化 → 丢弃一轮 → 工作模式），ZUC-128
> **5 个原子块 + 1 个完整块。** 完整块路径工作区可见 ~7 块，约 5 分钟搭建；原子教学路径另加 ~10 分钟。
> 输入：`key`（16 字节）、`iv`（16 字节）、`len`（输出字数）。输出：密钥流字数组（每字 32-bit，共 `len` 字）。

---

## 算法流程

```
ZUC 密钥流生成（GB/T 33133.1-2016 §5）
  └─ 密钥装入：s_i = k_i ‖ d_i ‖ iv_i（i=0..15）   // 31-bit 单元，d_i 为 8-bit 常量
  └─ 初始化模式（重复 32 拍）：
  │    └─ BitReconstruction()            // X0..X3 = s15H‖s14L、s11L‖s9H、s7L‖s5H、s2L‖s0H
  │    └─ W = F(X0, X1, X2)              // 更新 R1/R2 记忆单元
  │    └─ LFSRWithInitialisationMode(u = W>>>1)   // 模 2³¹-1 反馈 + u
  └─ 丢弃一轮：BitReconstruction → F → LFSRWithWorkMode()   // 输出丢弃
  └─ 工作模式（每拍输出一个字 z）：
       └─ BitReconstruction()
       └─ z = F(X0, X1, X2) ⊕ X3
       └─ LFSRWithWorkMode()
```

密钥流循环依赖：`R1/R2` 记忆单元跨拍持久化（F 块内部维护），LFSR 状态逐拍移位（初始化模式注入 `W>>>1`，工作模式不注入）。

## 参数

| 组件 | 参数 | 说明 |
|------|------|------|
| LFSR | 16 × 31-bit 单元 s₀..s₁₅ | 模 2³¹−1 加法的线性反馈移位寄存器 |
| 常量串 d_i | 8-bit × 16 | `0x44D7,0x26BC,0x626B,0x135E,0x5789,0x35E2,0x7135,0x09AF,0x4D78,0x2F13,0x6BC4,0x1AF1,0x5E26,0x3C4D,0x789A,0x47AC` |
| BR | 比特重组 | X₀ = s₁₅H‖s₁₄L、X₁ = s₁₁L‖s₉H、X₂ = s₇L‖s₅H、X₃ = s₂L‖s₀H |
| S0 / S1 | 8×8 S-box | GB/T 33133 附录 A.1 / A.2 |
| L1 | 32-bit 线性变换 | L1(X) = X⊕(X<<<2)⊕(X<<<10)⊕(X<<<18)⊕(X<<<24) |
| L2 | 32-bit 线性变换 | L2(X) = X⊕(X<<<8)⊕(X<<<14)⊕(X<<<22)⊕(X<<<30) |
| F | 非线性函数 | W = (X₀⊕R₁)⊞R₂；R₁'=S(L1(W₁‖W₂))、R₂'=S(L2(W₂‖W₁)) |
| 密钥流字 | 32-bit | z = W ⊕ X₃，每拍 1 字 |

## 原子块角色表

| 原子块 | Blockly ID | 角色 | 公式 |
|--------|------------|------|------|
| `ZUC S0` | `zuc_s0` | 8×8 S0 S-box 查表 | S0(x)，x ∈ 0..255 |
| `ZUC S1` | `zuc_s1` | 8×8 S1 S-box 查表 | S1(x)，x ∈ 0..255 |
| `ZUC L1` | `zuc_l1` | 线性变换 L1 | L1(X)，见参数表 |
| `ZUC L2` | `zuc_l2` | 线性变换 L2 | L2(X)，见参数表 |
| `ZUC F` | `zuc_f` | 非线性函数 F | W=(X₀⊕R₁)⊞R₂；R₁/R₂ 更新在生成器内完成 |
| `ZUC Keystream` | `zuc_keystream` | 完整密钥流（含 LFSR 循环） | 密钥装入 + 32 轮初始化 + 丢弃轮 + 工作模式 |

S 盒交织：S(x) = S0(x>>24) ‖ S1(x>>16) ‖ S0(x>>8) ‖ S1(x)（F 内部使用）。

## 前置：创建所有变量

拖任何逻辑块之前，先创建所有变量。避免 Blockly 后续自动创建类型错误的变量。

**「变量」→「创建变量」** — 按顺序逐一创建：

| # | 变量名 | 类型 | 用途 |
|---|--------|------|------|
| 1 | `key` | bytes | 初始密钥，16 字节（128 bit） |
| 2 | `iv` | bytes | 初始向量，16 字节（128 bit） |
| 3 | `len` | number | 输出密钥流字数 |
| 4 | `z` | IntList | 密钥流字数组（每字 32-bit） |
| 5 | `s0_out` | number | 教学变量：S0 查表输出 |
| 6 | `l1_out` | number | 教学变量：L1 输出 |

## 如何阅读每个步骤

| 符号 | 含义 |
|------|------|
| `──next──` | 将上一块的底部凹槽卡入本块顶部凸起（顺序执行） |
| `VALUE ←` | 将块拖入父块的 VALUE 输入插座 |

**从外向内搭建。** 先拖最外层块，再往内层插座填块。

## 步骤 1：初始化 key、iv、len

空文本占位符——运行时注入真实字节值（EEA3 测试数据的 key/iv 见「验证命令」节）。

### 1a — set key to

| # | 操作 |
|---|------|
| 1 | **变量** → 拖 `set key to` 到工作区左上角。 |
| 2 | 点击 VALUE 插座（右侧拼图缺口）。 |
| 3 | **数据处理与转换** → 拖 `""`（文本块）插入 VALUE 插座。文本字段留空。 |

### 1b — set iv to

| # | 操作 |
|---|------|
| 1 | **变量** → 拖 `set iv to`。卡入 1a 底部凸起（`──next──`）。 |
| 2 | VALUE ← **数据处理与转换** → `""`。留空。 |

### 1c — set len to

| # | 操作 |
|---|------|
| 1 | **变量** → 拖 `set len to`。卡入 1b 底部。 |
| 2 | VALUE ← **数学** → 数字块。将默认值 `0` 改为 `2`（或所需字数），回车。 |

```
[set key → ""]──next──[set iv → ""]──next──[set len → 2]
```

**块数**：3× `variables_set`、2× `text`、1× `math_number`

---

## 步骤 2：完整块路径 — ZUC Keystream(key, iv, len)

`zuc_keystream` 块在代码生成时内部展开完整 ZUC 流程（LFSR 循环 + 比特重组 + F，约 40 行生成代码）。工作区上只看到一个块。

| # | 操作 |
|---|------|
| 1 | **变量** → 拖 `set z to`。卡入步骤 1 底部。 |
| 2 | VALUE ← **祖冲之序列密码** → `ZUC Keystream`。 |
| 3 | KEY 插座 ← **变量** → `key`。 |
| 4 | IV 插座 ← **变量** → `iv`。 |
| 5 | LEN 插座 ← **变量** → `len`。 |

```
set z = ZUC Keystream(key=key, iv=iv, len=len)
```

**块数**：1× `set`、1× `zuc_keystream`、3× 变量引用

> **内部展开**（代码生成时）：密钥装入 `s_i = (k_i<<23) | (d_i<<8) | iv_i` → 32 拍初始化（每拍 BR → F → `lfsr(W>>>1)`，模 2³¹−1 加法）→ 丢弃一轮 → 工作模式逐字输出 `z = W ⊕ X₃`。输出为 IntList（每字 32-bit）。

---

## 步骤 3：模板路径 — 🔧 ZUC_Keystream

`proc_zuc_keystream` 是「加密模板」类目下的 procedure 模板：拖出即生成一个 `def ZUC_Keystream(key): return …` 函数，`key` 已连到形参，`iv`/`len` 插座留空待填。

| # | 操作 |
|---|------|
| 1 | **加密模板** → 拖 `🔧 ZUC_Keystream` 到工作区。 |
| 2 | 展开函数体，将 `iv` 插座 ← **变量** → `iv`；`len` 插座 ← **变量** → `len`。 |
| 3 | 调用方用 **函数** → `ZUC_Keystream` 引用块，KEY 传 `key`。 |

```
def ZUC_Keystream(key):
  return zuc_keystream(key, iv, len)
```

**块数**：1× 模板块（展开为 procedures_defreturn + zuc_keystream + 变量引用）

## 步骤 4：原子教学路径 — S0/S1/L1/L2/F 验证

用 C1 测试向量（附录 A）第 0 拍的已知值验证各原子块，理解每个块的角色。

### 4a — S0 / S1 查表

| # | 操作 |
|---|------|
| 1 | **变量** → 拖 `set s0_out to`。 |
| 2 | VALUE ← **祖冲之序列密码** → `ZUC S0`。INPUT ← **数学** → `0`。 |
| 3 | **变量** → 拖 `set l1_out to`。VALUE ← **祖冲之序列密码** → `ZUC L1`。INPUT ← **数学** → `1`。 |

```
set s0_out = ZUC S0(0)     // 期望 62（0x3e，附录 A.1 表第 1 项）
set l1_out = ZUC L1(1)     // 期望 16988165（0x01040405）
```

### 4b — F 函数单拍验证

初始 R₁=R₂=0，取 C1 第 0 拍输入：X₀=0x008f9a00、X₁=0xf100005e、X₂=0xaf00006b。

| # | 操作 |
|---|------|
| 1 | **变量** → 拖 `set w to`。 |
| 2 | VALUE ← **祖冲之序列密码** → `ZUC F`。 |
| 3 | X0 ← **数据处理与转换** → `value` 块，输入 `0x008f9a00`。 |
| 4 | X1 ← `value` 块，输入 `0xf100005e`。X2 ← `value` 块，输入 `0xaf00006b`。 |
| 5 | R1 ← `value` 块，输入 `0`。R2 ← `value` 块，输入 `0`。 |

```
set w = ZUC F(0x008f9a00, 0xf100005e, 0xaf00006b, 0, 0)
        // 期望 W = 0x008f9a00（= X₀，因 R₁=R₂=0）
```

> **说明**：`zuc_f` 块返回 W；R₁'/R₂' 的更新由生成器内部完成（纯函数版本返回 `{W, R1, R2}`）。密钥流生成循环（数据依赖的 LFSR 移位 + 逐拍 F）由 `zuc_keystream` 完整块承担——与 ML-KEM Encaps 指南同理，多步多中间量的循环算法不拆成工作区原子链。

**块数**（步骤 4）：2× `set`、1× `zuc_s0`、1× `zuc_l1`、1× `zuc_f`、4× `data_value`、1× `math_number`
