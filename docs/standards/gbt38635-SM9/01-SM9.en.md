## Formula or Pseudocode

### 1. Bilinear pairing and curve parameters

SM9 uses a 256-bit BN curve and the bilinear pairing `e: G1 × G2 → GT` (GB/T 38635.1, Annex A).

Annex A lists each Fq² coordinate as `(a1,a0) = a1·u+a0`; the table rewrites each as constant term plus the coefficient of `u`.

### 2. Key generation (Part 2, §6.1)

- The KGC selects a master signing secret `ks ∈ [1,N−1]` and publishes `Ppub = [ks]P2` in G2 (128 bytes, encoded as `x0‖x1‖y0‖y1`).
- For user identity `IDA`, the signing blocks fix `hid = 0x01`; compute `t1 = H1(IDA‖0x01,N)` and `deA = [ks·(t1+ks)⁻¹]P1` (64-byte G1 point). If `t1+ks = 0 mod N`, the master signing secret and public key must be regenerated, and existing user keys updated.

### 3. Digital signature (Part 2, §6)

Signing:

```text
g = e(P1, Ppub)
w = g^r, where r is sampled from [1,N−1]
h = H2(M‖w, N)
l = (r−h) mod N
S = [l]deA
Output (h,S): h is 32 bytes; S is a 65-byte uncompressed G1 point
```

Verification:

```text
g = e(P1,Ppub); t = g^h
Q = [H1(IDA‖hid,N)]P2 + Ppub
u = e(S,Q); w′ = u·t
h′ = H2(M‖w′,N)
Accept iff h = h′
```

### H1/H2 (Part 2, §§5.3.2.2–5.3.2.3)

The standard uses the domain-separation prefix `0x01` for H1 and `0x02` for H2, followed by `Z` and a 32-bit big-endian counter `ct` starting at 1. Concatenate enough `Hv` outputs to reach the standard-defined `hlen`, take the leftmost `hlen` bits, then compute `(OS2IP(Ha) mod (N−1))+1`. This project uses SM3. For the 256-bit SM9 group order, `hlen` is 320 bits: the implementation concatenates two SM3 outputs and takes the first 40 bytes.

## CipherCat blocks

- `sm9_master_key(ks)` returns `Ppub = [ks]P2` (128-byte G2 point).
- `sm9_user_key(ks,id)` returns `deA = [ks·(H1(ID‖0x01)+ks)⁻¹]P1` (64-byte G1 point).
- `sm9_sign(sk,m)` returns `(h,S)`; the regression uses GB/T 38635.2 Annex A.2 (`ks=0130E784…`, `IDA=Alice`, `hid=01`).
- `sm9_verify(pk,m,sig)` returns a Boolean.

GB/T 38635 consists of Parts 1 and 2. The project does not implement Part 2, Chapter 7 (key exchange), Chapter 8 (key encapsulation), or Chapter 9 (public-key encryption). Parameters and auxiliary functions from Chapter 5 are structured in the [parameters and H1/H2 entry](./02-H1-H2-and-Parameters.en.md).
