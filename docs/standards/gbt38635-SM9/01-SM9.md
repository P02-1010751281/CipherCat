### 2 密钥生成（第 2 部分 §5）

- **KGC 主密钥**：ks 随机 ∈ [1, N−1]；签名主公钥 `Ppub = [ks]P2`（G2 点，128 字节 = x0‖x1‖y0‖y1）
- **用户签名私钥**：t1 = H1(IDA ‖ hid, N)（hid = 0x01，签名标识符）；
  `deA = [ks · (t1 + ks)⁻¹]P1`（G1 点，64 字节 = x‖y）

### 3 数字签名（第 2 部分 §6）

### 签名

```
g = e(P1, Ppub)                      # 预计算
w = g^r，r 随机 ∈ [1, N−1]
h = H2(M ‖ w, N)                     # H2 输出 (0x02‖M‖w 的 SM3 摘要 mod (N−1)) + 1
l = (r − h) mod N
S = [l]deA
输出签名 (h, S)                       # h 32 字节，S 65 字节（04 前缀 G1 点）
```

### 验签

```
g = e(P1, Ppub)；t = g^h
Q = [H1(IDA ‖ hid, N)]P2 + Ppub     # 用户公钥
u = e(S, Q)；w′ = u · t
h′ = H2(M ‖ w′, N)
接受 ⟺ h == h′
```

### H1/H2（§5.2，基于 SM3）

- H1(z, n)：`H(z ‖ 0x01) 的 SM3 摘要转整数 mod (N−1) + 1`（首字节 0x01）
- H2(z, n)：`H(z ‖ 0x02) 的 SM3 摘要转整数 mod (N−1) + 1`（首字节 0x02）

## 4 CipherCat 块实现

- `sm9_master_key(ks)` → Ppub = [ks]P2（G2 128 字节）
- `sm9_user_key(ks, id, hid)` → deA = [ks·(H1(ID‖hid)+ks)⁻¹]P1（G1 64 字节）
- `sm9_sign(sk, m)` → (h, S)，官方向量 GB/T 38635.2 附录 A.2（ks=0130E784…/IDA=Alice/hid=01）
- `sm9_verify(pk, m, sig)` → Boolean
