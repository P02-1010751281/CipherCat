## 检测项目

| 项目族 | 检测项目 |
|---|---|
| 频数 | 单比特频数、块内频数、扑克 |
| 子序列/游程 | 重叠子序列、游程总数、游程分布、块内最大游程 |
| 关系 | 二元推导、自相关 |
| 矩阵/累加 | 矩阵秩、累加和 |
| 复杂度/谱 | 近似熵、线性复杂度、Maurer 通用统计、离散傅立叶 |

合计 15 项。样本通过率、样本分布均匀性、显著性水平、样本量和参数边界必须以 PDF 条款为准；本表不是测评结果。

## 项目边界

检测项目不是 CipherCat Blockly 原语。它们由 `metacrypt_server` Go 后端执行并写入测评报告。
