## 检测项

GM/T 0005-2021 规定 15 项检测（参考 NIST SP 800-22 体系）：单比特频数、块内频数、
游程、最大游程、矩阵秩、FFT、重叠模板、通用统计、Lempel-Ziv、线性复杂度、序列、
近似熵、累加和、随机游动、随机游动状态频数。2021 版在样本通过率判定基础上增加
**样本均匀性判定**（§6.3）。
