## 必查参数

| 参数 | 约束 |
|---|---|
| 口令 `P` | 按明确字符/字节编码处理 |
| 盐 `S` | 应独立、不可预测并与口令分离 |
| 迭代次数 `c` | 必须为正，并按系统策略可升级 |
| 派生长度 `dkLen` | 不超过 PBKDF2/PRF 的编码和实现上限 |

PBKDF2 只提供派生构造；口令存储格式、参数升级、验证式解码和账户策略不在当前块内。Demo 成功不能单独证明口令安全。
