## 标准定义

`pC` 在每一轮把轮常量加到 320-bit 状态的 `S2` lane；轮数为 `rnd` 时使用
`c_i = const_(16-rnd+i)`。常量表和轮号偏移是规范的一部分。

## 原文定位与引用

本页从 [§3.2 原文](./00-Standard-Source.md#L609) 拆出；完整 Table 5、图示和上下文回到 source 与 PDF 核验。

## 原文摘录

> The constant-addition layer `pC` adds a 64-bit round constant `c_i` to `S_2` in round `i`.
> `c_i = const_(16-rnd+i)`；[source](./00-Standard-Source.md#L609)

## 公式或伪代码

```text
c_i = const_(16 - rnd + i)
S_2 = S_2 xor c_i
```

标准 Table 5 的 `const_i` 取值也必须保留；本页不重排为项目自定义常量。

## 输入与输出

| 项目 | 约束 |
|---|---|
| 输入 | 5 个 64-bit lane、轮号 `i`、置换轮数 `rnd` |
| 输出 | 仅更新 `S2` 的 64-bit 状态 |
| 约束 | `rnd ≤ 16`；具体轮数由 `Ascon-p[8]` 或 `Ascon-p[12]` 决定 |

## 项目映射

`pC` 由 `ascon_encrypt` 内部置换实现；没有独立块，不得把高层 AEAD 结果当作该层独立向量。

## 核验与缺项

核对 Table 5、`p[8]`/`p[12]` 的常量偏移和每轮 `S2` 变化；独立中间状态向量尚未接入。
