## 标准定义

`pS` 对 `j = 0..63` 的 64 个 bit slice 并行应用 5-bit `SBOX`，每个 slice 的输入输出均为
`(s(0,j), …, s(4,j))`。标准同时给出布尔电路公式和 lookup table。

## 原文定位与引用

本页从 [§3.3 原文](./00-Standard-Source.md#L647) 拆出；完整公式、Table 6 和电路图回到 source 与 PDF 核验。

## 原文摘录

> The substitution layer `pS` updates the state with 64 parallel applications of the 5-bit substitution box `SBOX`。
> `(s(0,j), …, s(4,j)) = SBOX(s(0,j), …, s(4,j))`，`0 ≤ j < 64`；[source](./00-Standard-Source.md#L647)

## 公式或伪代码

```text
for j = 0 .. 63:
    (s0[j], s1[j], s2[j], s3[j], s4[j])
        = SBOX(s0[j], s1[j], s2[j], s3[j], s4[j])

(y0,y1,y2,y3,y4) = SBOX(x0,x1,x2,x3,x4)
y0 = x4*x1 xor x3 xor x2*x1 xor x2 xor x1*x0 xor x1 xor x0
y1 = x4 xor x3*x2 xor x3*x1 xor x3 xor x2*x1 xor x2 xor x1 xor x0
y2 = x4*x3 xor x4 xor x2 xor x1 xor 1
y3 = x4*x0 xor x4 xor x3*x0 xor x3 xor x2 xor x1 xor x0
y4 = x4*x1 xor x4 xor x3 xor x1*x0 xor x1
```

`*` 是 bitwise AND；实现可用标准 Table 6 lookup，但必须保持 5-bit 编码约定。

## 输入与输出

| 项目 | 约束 |
|---|---|
| 输入 | 320-bit 状态，按 64 个 5-bit slice 解释 |
| 输出 | 同形状 320-bit 状态 |
| 取值域 | 每个 `x/y` 为 bit；lookup 输入为 0..31 |

## 项目映射

`pS` 由 `ascon_encrypt` 内部置换实现；没有独立块。若开放原子块，必须同时固定 bit-slice 与 Table 6 编码。

## 核验与缺项

核对公式 (7)、Table 6 和置换中间状态；独立 S 盒向量尚未接入。
