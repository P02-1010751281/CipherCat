## 标准定义

`pL` 对五个 64-bit state word 分别应用线性函数 `Σ_i`，提供每个 word 内的扩散。

## 原文定位与引用

本页从 [§3.4 原文](./00-Standard-Source.md#L699) 拆出；完整图示和旋转符号定义回到 source 与 PDF 核验。

## 原文摘录

> The linear diffusion layer `pL` provides diffusion within each 64-bit word `S_i`。
> `S_i ← Σ_i(S_i)` for `0 ≤ i ≤ 4`；[source](./00-Standard-Source.md#L699)

## 公式或伪代码

```text
Σ0(S0) = S0 xor (S0 >>> 19) xor (S0 >>> 28)
Σ1(S1) = S1 xor (S1 >>> 61) xor (S1 >>> 39)
Σ2(S2) = S2 xor (S2 >>> 1)  xor (S2 >>> 6)
Σ3(S3) = S3 xor (S3 >>> 10) xor (S3 >>> 17)
Σ4(S4) = S4 xor (S4 >>> 7)  xor (S4 >>> 41)
```

`>>>` 表示标准定义的 64-bit 循环右移；不能用无限精度整数右移替代。

## 输入与输出

| 项目 | 约束 |
|---|---|
| 输入 | 五个 64-bit unsigned words |
| 输出 | 五个更新后的 64-bit words |
| 操作 | 固定宽度 64-bit XOR 与循环右移 |

## 项目映射

`pL` 由 `ascon_encrypt` 内部置换实现；没有独立块。

## 核验与缺项

核对五组旋转量及每轮中 `pC → pS → pL` 的顺序；独立层向量尚未接入。
