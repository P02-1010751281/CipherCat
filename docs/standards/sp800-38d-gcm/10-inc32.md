## 标准定义

`inc_s(X)` 保留 `X` 的左侧 `len(X)-s` 位，只对最右侧 `s` 位作为整数加一并按 `2^s` 取模。
GCM 的计数器使用 `inc32`，即 `s=32`。

## 原文定位与引用

本页从 [§6.2 原文](./00-Standard-Source.md#L745) 拆出；完整 bit-string 运算定义回到 source 与 PDF 核验。

## 原文摘录

> The function increments the right-most `s` bits of the string, regarded as the binary representation of an integer,
> modulo `2^s`; the remaining bits remain unchanged；[source](./00-Standard-Source.md#L745)

## 公式或伪代码

```text
inc_s(X) = MSB_(len(X)-s)(X) || [int(LSB_s(X)) + 1 mod 2^s]_s
inc32(X) = inc_s(X) with s = 32
```

## 输入与输出

| 项目 | 约束 |
|---|---|
| 输入 | 长度至少 32 bit 的 bit string / 128-bit GCM counter block |
| 输出 | 与输入等长；仅低 32 bit 递增并回绕 |
| 错误条件 | `len(X) < s` 时不满足标准前置条件 |

## 项目映射

`gcm_encrypt` 内部使用计数器递增；没有独立 `inc32` 块。

## 核验与缺项

核对低 32-bit 从 `0xffffffff` 回绕到零且高位保持不变；独立边界向量尚未接入。
